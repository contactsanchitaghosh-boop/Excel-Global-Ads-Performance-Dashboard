
# Global Ads Performance Dashboard  
Marketing Data Analysis Project | Microsoft Excel  

---

## Project Overview  

This project presents an end-to-end advertising performance analysis using Microsoft Excel.  
The objective is to evaluate campaign effectiveness across platforms, countries, and industries, and to build an interactive dashboard for business insights.

The workflow includes structured data analysis, KPI calculation, and interactive dashboard development.

---

## File Structure  

The Excel file contains three sheets:

1. Global Ads Performance Dataset – Raw advertising dataset  
2. Performance Analysis – Pivot-based calculations and metrics  
3. Dashboard – Interactive visualization with KPIs and slicers  

All components are integrated within a single Excel file.

---

## Key Business Questions  

- What is the total revenue generated?  
- How much total ad spend was incurred?  
- Which platforms generate the highest revenue and conversions?  
- How does revenue vary by country?  
- What is the revenue share by industry?  
- How do revenue and ad spend trend over time?  

---

## Key Performance Indicators (KPIs)

- Total Revenue  
- Total Ad Spend  
- Total Conversions  
- Average CPA  
- Average ROAS  
- Average CTR  

---

## Dashboard Features  

- Revenue vs Ad Spend by Platform  
- Revenue by Country  
- Revenue Share by Industry  
- Monthly Revenue and Ad Spend Trend  
- Interactive slicers for Platform, Country, and Industry  

---

## Tools Used  

- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  
- KPI Calculations
